# UX/UI WPF Guidelines
- Dark palette (#0E0E0E background, #1E1E1E cards/inputs, #3A3A42 borders, #7856FF accent)
- Rounded corners (6px), consistent padding/margins
- Subtle hover (lighter accent), pressed (darker), disabled state
- Use custom MessageBox styled in dark mode
- Copy useful templates/references into created folders
- Prefer XAML styles over inline repeated styles
- Keep layout clear and readable
