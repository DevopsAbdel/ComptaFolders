Guide d'utilisation - Créateur de dossiers clients comptables

Étapes d'utilisation

  1. Sélection de l'année : Par défaut l'année en cours, modifiable pour les dossiers antérieurs.
  2. Saisie de la société : Le nom est automatiquement converti en majuscules et les espaces sont remplacés par des underscores (_). Les caractères interdits par Windows sont supprimés.
  3. Sélection du chemin parent : Choisir l'emplacement racine où sera créé le dossier YYYY_SOCIETE.
  4. Vérification : L'application vérifie que le dossier racine n'existe pas déjà.
  5. Création : Génération de l'arborescence complète, copie de la charte et des fiches repères, puis génération du rapport d'inventaire HTML.

Options disponibles

  • Ouvrir le dossier après création : Ouvre automatiquement le dossier racine dans l'Explorateur Windows.
  • Guide / Index documents : Accès direct à la documentation intégrée.

Lancement

.\Create-DossierClient-GUI.ps1 ou via le raccourci de l'application.
