# Charte de nommage des fichiers

## Dossier racine
`YYYY_SOCIETE_MAJUSCULE` (ex: `2026_GEAR_MANIA`).

## Conversion societe
Le nom saisit est converti en majuscules, les espaces deviennent `_`, les caracteres invalides Windows sont supprimes.

## Prefixes numerotes
Tous les dossiers principaux portent un prefixe a deux chiffres (`00-` ... `99-`).

## Fichiers types
- Scans TVA complets : `YYYY-MM_TVA_SOCIETE_Dos-complet.pdf`
- Recipisses / Declarations TVA : `YYYY-MM_Recu_Decl_Tva_SOCIETE.pdf`
- Excel TVA (Deductions) : `Deductions_SOCIETE_MM_YYYY.xlsx`
- Archives XML TVA : `Releve_Deductions_MM_YYYY.zip`
- Delais de paiement : `Convention_delais_paiement_FOURNISSEUR.docx`, `Convention delais de paiement FOURNISSEUR Scan.pdf`, `YYYY-XTr_Recu_Decl_Delais_Paiement_SOCIETE.pdf`
- Attestations fiscales : `YYYY-MM_Attestation_CA_SOCIETE.pdf`, `YYYY-MM_IF_SOCIETE.pdf`, `YYYY-MM_TP_SOCIETE.pdf`
